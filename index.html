Educational Theory & Concepts Guide
Address Translation Math

Virtual addresses are split into two parts:

VPN = ⌊Virtual Address / Page Size⌋
Offset = Virtual Address % Page Size
Physical Address = (PFN × Page Size) + Offset

The TLB accelerates lookup by caching recent (VPN → PFN) translations directly inside the MMU.

Traditional TLB vs FIFO

Stores individual page translations. On TLB Hit, physical frame is retrieved in ~1 clock cycle.

On TLB Miss, a slower Demand Page-Table Walk in main memory occurs. The mapping is then cached.

FIFO Policy: When full, the earliest inserted entry is evicted regardless of recent use.

Research Coalescing & Prefetch

Inspired by "Contiguity aware TLB prefetching for embedded I/O devices" (IEICE Electronics Express, 2025).

Coalescing: Multiple consecutive virtual pages are merged into one TLB slot when their physical frames are consecutive.

Prefetching: On a block hit, the next sequential block (Start + Size) is automatically pre-cached ahead of demand.
